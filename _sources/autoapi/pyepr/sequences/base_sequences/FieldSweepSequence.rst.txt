pyepr.sequences.base_sequences.FieldSweepSequence
=================================================

.. py:currentmodule:: pyepr.sequences.base_sequences

.. py:class:: FieldSweepSequence(*, B, freq, Bwidth, reptime, averages, shots, **kwargs)

   Bases: :py:obj:`HahnEchoSequence`


   Represents a Field Sweep (EDFS) sequence. 





   Build a Field Sweep (EDFS) sequence using either rectangular pulses or
   specified pulses.

   Sequence:
   [\pi/2 - \tau - \pi - \tau - echo]

   :Parameters:

       **B** : int or float
           The B0 field, in Gauss

       **Bwidth: int or float**
           The width of the field sweep, in Gauss

       **freq** : int or float
           The freq frequency in GHz

       **reptime** : _type_
           The shot repetition time in us

       **averages** : int
           The number of scans.

       **shots** : int
           The number of shots per point













   .. rubric:: Examples

   .. plot::
       :include-source:

       import pyepr as epr
       epr.set_waveform_precision(1)

       seq = epr.FieldSweepSequence(
       B=12000, Bwidth=100, freq=34, reptime=1e3, averages=1, shots=10)
       seq.draw()

      Simulate the Field Sweep spectra as a Nitroxide radical.





      :Returns:

          **axis** : np.ndarray
              The magnetic field axis in Gauss

          **data** : np.ndarray
              The simulated complex echo intensity










      .. rubric:: Examples

      .. plot::
          :include-source:

          import matplotlib.pyplot as plt
          import pyepr as epr
          epr.set_waveform_precision(1)

          N_gyro = 0.002803632236095
          freq = 34
          seq = epr.FieldSweepSequence(
              B=freq/N_gyro, Bwidth=200, freq=freq, reptime=1e3, averages=1, shots=10)
          B, data = seq.simulate()
          plt.plot(B, data.real)
          plt.xlabel("Magnetic Field (G)")
          plt.ylabel("Signal Intensity (a.u.)")
