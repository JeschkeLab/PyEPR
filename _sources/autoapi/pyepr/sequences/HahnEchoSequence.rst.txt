pyepr.sequences.HahnEchoSequence
================================

.. py:currentmodule:: pyepr.sequences

.. py:class:: HahnEchoSequence(*, B, freq, reptime, averages, shots, **kwargs)

   Bases: :py:obj:`Sequence`


   Represents a Hahn-Echo sequence. 


   Build a Hahn-Echo sequence using either rectangular pulses or
   specified pulses. By default no progression is added to this sequence.

   Sequence:
   [\pi/2 - \tau - \pi - \tau - echo]

   :Parameters:

       **B** : int or float
           The B0 field, in Gauss

       **freq** : int or float
           The freq frequency in GHz

       **reptime** : _type_
           The shot repetition time in us

       **averages** : int
           The number of scans.

       **shots** : int
           The number of shots per point













   .. rubric:: Examples

   .. plot::
       :include-source:

       import pyepr as epr
       import numpy as np

       epr.set_waveform_precision(1)
       seq = epr.HahnEchoSequence(
           B=12000, freq=34, reptime=1e3, averages=1, shots=10, tau=500)
       seq.draw()

   .. py:method:: simulate(Tm=1000.0)

      
      Simulates the Hahn echo intensity as a stretched exponential decay
      of the interpulse delay, with a stretching exponent of 1.6.

      .. math::
          V(\tau) = e^{-(\tau/T_m)^{1.6}}

      :Parameters:

          **Tm** : float
              The phase memory time in ns, by default 1e3 ns



      :Returns:

          **xaxis** : np.ndarray
              The interpulse delay in ns (a single point)

          **data** : np.ndarray
              The simulated complex echo intensity (a single point)










      .. rubric:: Examples

      .. code-block:: python

          import pyepr as epr
          seq = epr.HahnEchoSequence(
              B=12000, freq=34, reptime=1e3, averages=1, shots=10, tau=500)
          tau, data = seq.simulate(Tm=1e3)
          print(tau, data)
