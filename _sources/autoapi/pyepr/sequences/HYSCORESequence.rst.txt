pyepr.sequences.HYSCORESequence
===============================

.. py:currentmodule:: pyepr.sequences

.. py:class:: HYSCORESequence(*, B, freq, reptime, averages, shots, tau=300, start=300, step=16, dim=128, **kwargs)

   Bases: :py:obj:`pyepr.sequences.Sequence`


   Represents an experimental pulse sequence.


   Creates a HYSCORE sequence object.
   In the form of [\pi/2 -         au - \pi/2 - T1 - \pi - T2 - \pi/2 - echo]


   :Parameters:

       **B** : float
           The B0 field in Gauss.

       **freq** : float
           The frequency in GHz.

       **reptime** : float
           The shot repetition time in us.

       **averages** : int
           The number of scans.

       **shots** : int
           The number of shots per point.

       **tau** : float, optional
           The first interpulse delay in us, by default 300.

       **start** : float, optional
           The starting mixing time in ns, by default 300.

       **step** : float, optional
           The step size for the mixing time in ns, by default 16.

       **dim** : int, optional
           The number of points in the mixing time, by default 128.













   .. rubric:: Examples

   .. plot::
       :include-source:

       import pyepr as epr
       epr.set_waveform_precision(1)

       seq = epr.HYSCORESequence(
           B=12000, freq=34, reptime=1000, averages=1, shots=10,
           tau=300, start=300, step=16, dim=128)
       seq.draw()
